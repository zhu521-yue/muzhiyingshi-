## 多公司勤奋指数看板优化与打包

### 1. 性能优化 (server.py)
- 延迟导入 `core` 模块，启动更快
- 新增 `_find_superset_cache()` 函数：请求子集月份时自动查找超集缓存
- `preload_widest_cache()` 启动时预加载最宽缓存到内存
- 新增 `/api/status` 端点供 GUI 启动器监控

### 2. 核心缓存增强 (core.py)
- 新增 `filter_data_to_months()` 函数：从全量数据中提取子集月份，避免重新请求钉钉API
- 前端和后端均支持超集缓存命中

### 3. 前端查询缓存 (_html_template.py)
- 新增 `_dataCache` Map 存储已获取数据
- 查询时三级命中：精确缓存 → 超集缓存 → 服务端获取
- 新增 `filterDataToMonths()` JS函数实现客户端子集过滤
- 后台静默刷新：缓存命中时立即展示，同时后台获取最新数据

### 4. GUI启动器 (launcher.py)
- 完全重写 tkinter GUI 界面（暗色主题）
- 实时显示端口状态、首页访问状态、缓存文件数量
- 各公司看板状态一览（缓存状态圆点 + 可访问性）
- 可折叠运行日志
- 最小化窗口不停止服务
- 启动时自动打开浏览器

### 5. Exe打包
- 入口: launcher.py（无 CMD 窗口 --windowed）
- 预置 config/ 配置（4家公司）+ cache/ 缓存文件
- 所有静态资源（图片、JS）打包进 exe
- 输出: dist/勤奋指数看板.exe (8.8MB) + 完整版.zip (8.6MB)
- 到其他环境只需解压 zip，双击 exe 即可运行
